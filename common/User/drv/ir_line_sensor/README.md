# 新版 8 路循迹模块

新版模块内部带 MCU，不再使用旧版的三根地址线、模拟多路复用器和 ADC。
当前工程使用 I²C 数字输出：7 位地址 `0x30`，读取寄存器 `0x50`，返回的
一个字节中 `bit0..bit7` 分别表示第 1..8 路是否检测到黑线。

- STM32：硬件 I2C1，PB8=SCL、PB9=SDA，与 OLED 共用总线。
- MSPM0：软件 I²C，PA4=SCL、PA3=SDA，与 OLED 共用总线。
- 模块内部更新频率为 50 Hz，工程按 20 ms 周期读取。
- 模块已经自行完成阈值处理，不需要黑白校准；`normalized[]` 只输出 0 或 1。

旧版 `track_sensor` 驱动保留在仓库中仅供历史对照，比赛运行链路不再初始化或调用它。
