# 循迹归中模式（底盘运动补偿第一版）

## 目标与当前边界

管道沿小车前后中轴线安装。当前尚未接入小球位置观测，因此程序只能根据底盘纵向加速度主动改变管道倾角，尽量抵消车辆加减速造成的惯性作用；它还不能识别并拉回已经偏离中心的小球。预测的小球位置只用于 OctoLink 观察，不参与控制。

本版严格拆分两个传感器的职责：

- 杆上的 DM-IMU-L1：只测管道 `roll` 和角速度。
- 底板 BMI088：测车体加速度，不再使用杆上IMU的加速度参与底盘补偿。
- 轮编码器：实际发车后参与加速度融合；手推模式中编码器不更新，因此不参与。

这样可以切断“丝杆运动→杆上IMU检测到运动→误判成底盘加速度→丝杆继续动作”的自激闭环。

## 启用与按键

在 `common/User/config/knexus_config.h` 中只启用：

```c
#define KNEXUS_MODE_LINE_FOLLOW_BALL_CENTER
```

当前 `KNEXUS_BALL_MANUAL_COMP_TEST_ENABLE=0`，已经接回比赛巡线逻辑：

1. KEY0完成循迹阈值校准，同时等待BMI088零偏完成。
2. READY阶段丝杆先把杆归到 `0°`。
3. KEY1启动巡线；底盘加速度规划同步作为丝杆前馈。
4. 再按KEY1或任务完成时，底盘减速指令同步参与补偿。

## 静止稳定策略

静止锁采用迟滞：BMI088纵向滤波加速度连续30 ms超过 `0.25 m/s²` 时解除锁定；回落到 `0.10 m/s²` 以下并持续200 ms后重新锁零。预归零期间强制保持静止锁，避免丝杆自身动作被识别为底盘运动。

目标角速度前馈恢复为较小的 `8 rpm/(deg/s)`，在60°/s目标斜率下最多增加480 rpm。补偿加速度乘以1.15，用于抵消滤波和机械响应的实际滞后。

## BMI088轴向和加速度来源

2026-07-31手推“先前进、再后退”数据已经确认底板BMI088车头方向为 `-Y`，因此默认配置为：

```c
KNEXUS_BALL_ACCEL_AXIS_DEFAULT = 1
KNEXUS_BALL_ACCEL_AXIS_SIGN_DEFAULT = -1.0f
```

巡线时不直接让BMI088噪声生成杆角目标：85%使用巡线模块已经限加速度、限加加速度的速度规划前馈，剩余15%由BMI088/编码器融合结果修正。纵向加速度限制为 `+0.65/-0.75 m/s²`，加加速度限制为 `3.5 m/s³`，均处在管道机械倾角可补偿的范围内。轴向在线学习代码仍然保留，但当前关闭。

## 钢球模型

- 直径：10 mm
- 材料：GCr15，估算质量约4.09 g
- 理想实心球纯滚动系数：`5/7`
- 第一版等效粘性阻力：`0 s^-1`

相对管道的小球预测加速度使用底盘加速度和当前杆角重力分量共同计算。后续接入视觉位置后，再加入小球位置、速度反馈并辨识阻力常数。

## 模块边界

- `knx_ball_motion_comp`：重力分离、BMI088轴向学习、加速度融合、静止锁零和小球运动预测。
- `knx_rod_runtime`：DM-IMU-L1、C620/M3508、杆角闭环、反馈超时和方向限位。
- `knexus_mode_line_follow_ball_center`：组合循迹核心与上述模块，不把视觉协议写入电机驱动层。
