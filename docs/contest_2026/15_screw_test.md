# 丝杆与DM-IMU-L1测试模式

在 `common/User/config/knexus_config.h` 中只启用：

```c
#define KNEXUS_MODE_SCREW_TEST
```

该组合仅支持STM32版本：FDCAN2连接C620/M3508，FDCAN1连接DM-IMU-L1。

- 按住KEY0：目标速度 `+1000 rpm`，丝杆下沉、roll增大，松开立即停止。
- 按住KEY1：目标速度 `-1000 rpm`，丝杆上升、roll减小，松开立即停止。
- KEY0和KEY1同时按下：停止。
- `roll >= +7°`：下限位，禁止继续下沉，只允许上升离开。
- `roll <= -12°`：上限位，禁止继续上升，只允许下沉离开。
- IMU倾角未就绪或数据超过50ms：禁止电机动作。
- LED1亮：3508当前已使能。
- LED2亮：DM-IMU-L1的加速度、角速度、欧拉角和四元数均已接收。

速度可修改 `KNEXUS_SCREW_TEST_SPEED_RPM`，也可运行时修改
`knexus_screw_test_speed_rpm`。

## OctoLink变量

高频控制量：

- 900：方向（-1/0/+1）
- 901~905：目标、斜坡目标、反馈转速、电流、PID输出
- 906~909：外置IMU的roll、pitch、yaw、累计yaw
- 910：三轴角速度数组
- 911：3508累计轴角（deg），用于计算丝杆传动量与杆倾角的关系
- 912：3508反馈温度（℃）
- 913：DM-IMU连续roll（deg），杆倾角控制应使用此量并减去启动零点
- 914：DM-IMU连续pitch（deg）
- 915：按键请求方向（即使被限位屏蔽也保留）

低频诊断量：

- 916：平台是否支持
- 917/918：KEY0/KEY1状态
- 919：3508是否使能
- 920~926：3508初始化、收发计数和反馈年龄
- 927~929：DM-IMU路由及初始化状态
- 932：倒置安装修正后的roll，原始±180°映射为0°
- 933：MCU一维互补融合后的pitch
- 934~946：其余完整 `DM_IMU_L1_DebugOcto` 数据
- 947/948：由加速度重力方向直接计算的roll/pitch
- 949：加速度模长（m/s²）
- 950/951：互补滤波器就绪/重力校正有效标志
- 952/953：DM-IMU-L1模块内部原始融合roll/pitch，仅用于对比诊断
- 954：倾角数据是否可用
- 955：被限位屏蔽的方向，`-1`为上限位、`+1`为下限位、`0`为未屏蔽
- 956：限位拦截计数
- 957/958：上限位/下限位激活状态
- 959/960：上限位/下限位角度参数
