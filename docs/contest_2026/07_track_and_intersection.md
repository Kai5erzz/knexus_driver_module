# 巡线与路口识别

当前H题不启用路口TinyCNN；H题的A点横向启停线使用中央覆盖与连续黑路组合判定，详见
`14_h_balance_ball.md`。

> 当前默认主程序已启用本页的 KEY0 校准 / KEY1 巡线流程。25 cm / 90° 运动测试仍保留，可在 `knx26_config.h` 中切换回来。

## 当前 MSPM0 接线

- `PB15 / PB14 / PB13`：三位模拟多路复用器地址 `AD0 / AD1 / AD2`
- `PA16`：循迹模块模拟输出 ADC（当前飞线后的有效输入）
- 8 路原始值由 `TrackSensor_Scan()` 依次切换地址并采样

## 当前按键测试流程

本流程位于 `common/User/app/contest_2026/knx26_user.c`，全部为非阻塞状态机。

1. 把 8 个探头全部放在黑线上，按一次 `KEY0`。
2. LED1 快闪，等待 2 秒后自动采集 100 组黑线值。
3. 蜂鸣器响后，在接下来的 2 秒内把 8 个探头移到白底上。
4. LED1 慢闪，随后自动采集 100 组白底值。
5. 校准成功时 LED1 常亮并响一声；若任一路黑白 ADC 跨度小于 40，长鸣并拒绝启动。
6. 把车放回黑线上，按 `KEY1` 开始巡线。再次按 `KEY1` 可主动停止。
7. 已启用脱线停车：连续 150 ms 检测不到黑线后立即失能电机并鸣叫。短暂弱信号仍允许恢复转向；ADC 扫描失败或循迹数据超过 100 ms 未更新也会停机。

上电后校准值不保存，必须重新执行一次 KEY0 流程。校准期间和失败状态下电机始终失能。

## 初始控制参数

| 参数 | 初值 | 说明 |
|---|---:|---|
| `knx26_line_speed_mps` | 0.12 m/s | 前进速度 |
| `knx26_line_kp` | 0.35 | 位置误差比例增益 |
| `knx26_line_kd` | 0.02 | 位置误差微分增益 |
| `knx26_line_max_angular_radps` | 0.80 rad/s | 最大转向角速度 |
| `knx26_test_max_duty` | 0.30 | 两电机 PWM 最大占空比 |

`line_error < 0` 表示线偏左，`line_error > 0` 表示线偏右。控制器输出使用
`angular = -(Kp * error + Kd * derivative)`；若实车转向完全相反，优先检查 8 路传感器编号顺序，不要直接交换电机极性。

## OctoLink 变量（730 起）

| ID | 含义 |
|---:|---|
| 730 | 状态：0 空闲、1/2 黑线等待/采样、3/4 白底等待/采样、5 就绪、6 运行、7 手动停止、8 脱线、9 校准失败 |
| 731 | 已校准 |
| 732 | 正在巡线 |
| 733 | 当前校准采样数 |
| 734 | 8 路中的最小黑白 ADC 跨度 |
| 735 / 736 | 当前线速度 / 角速度指令 |
| 737-740 | 速度、Kp、Kd、最大角速度参数 |
| 741 / 742 | 停止次数 / 脱线次数 |
| 766 / 767 / 768 | 脱线确认中、已连续脱线时间ms、停车确认时间ms |
| 743 | PWM 占空比上限 |
| 744 / 745 | 左 / 右电机指令极性 |

当前 OctoLink 只发送处理后的 8 路归一化结果：`700-707` 分别对应 CH0-CH7，类型均为 F32，范围为 0.0-1.0；其他巡线、底盘和原始 ADC 调试流已关闭。

## 模块 API

```c
knx_track_update();
knx_track_snapshot(&track);
knx_track_set_calibration(black, white);
```

路口模块累积 64×8 窗口，识别结果通过 `knx26_user_on_intersection()` 通知上层。当前巡线试验只记录回调，不会因路口自动转向或停车。
