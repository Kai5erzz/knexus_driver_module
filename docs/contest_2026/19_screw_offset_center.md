# 上位机偏移量丝杆归中模式

该模式用于第一阶段钢球视觉归中：底盘始终静止，只使用FDCAN2上的C620/M3508
驱动丝杆，通过DM-IMU-L1测量管道杆角。JC4310不初始化、不发送控制帧。

## 启用模式

在`common/User/config/knexus_config.h`中只启用：

```c
#define KNEXUS_MODE_SCREW_OFFSET_CENTER
```

## 上位机协议

USART2使用PD5(TX)、PD6(RX)，参数为921600、8数据位、无校验、1停止位。

上位机每帧发送8字节：

| 字节 | 含义 |
|---:|---|
| 0 | `0xAA` |
| 1 | `0x55` |
| 2～5 | `float32`小端偏移量 |
| 6～7 | 前6字节的CRC16/Modbus，小端 |

偏移量必须连续发送。超过150 ms没有收到合法帧，电机立即停止且模式退出，必须在
通信恢复后重新按KEY0。

## 操作

1. 上电后3508保持失能，底盘左右轮保持失能。
2. 确认上位机正在发送合法偏移量，并等待DM-IMU-L1与3508反馈正常。
3. 按KEY0启动。短鸣表示进入闭环；长鸣表示通信或硬件条件未满足。
4. KEY1随时急停。急停后需要重新按KEY0才能再次启动。

控制采用级联结构：

```text
上位机偏移量 -> 偏移PID -> 目标杆角 -> DM-IMU杆角PID -> 3508目标转速
```

第一版沿用队友代码的偏移极性：正偏移产生正目标杆角。如果实测方向相反，只需将
`knexus_offset_input_sign`从`+1`改为`-1`，不要修改3508和DM-IMU底层极性。

## 限位与失效保护

- 外环目标杆角限制为`-5°～+5°`，目标换向速度为`35°/s`；更强的D项负责在过零前制动。
- 固定静摩擦补偿降低为最多`0.60°`，主要恢复力交给自适应抗静摩擦环，避免固定补偿在不同位置制造假平衡点。
- 归中模式单独使用3508速度PI、`5500`电流上限和`500`电流前馈，在保留刚性的同时减少低速换向振动；不会改变丝杆测试和其他模式的参数。
- 近零区使用额外比例刚度：越接近0，有效Kp越高，提升抗扰恢复力；远端仍保持较低Kp，避免大行程振荡。
- 防卡滞采用三阶段状态机：偏移在`300 ms`内变化不足`0.04`才进入破静摩擦，以`3°/s`累加；误差从`0.10`增至`0.50`时，恢复角上限由`0°`线性增至`3°`，因此接近零点时只施加小推力，远端仍可快速越过静摩擦。检测到真实位移立即清零，并冷却`500 ms`后才允许再次判断。
- 归中死区缩小到缩放误差`0.025`，约等于原始偏移`±5`。
- 上位机识别失败时实测会输出约`-700`（缩放后约`-3.5`）。固件拒绝原始值小于等于`-650`的负边缘异常，不会把它送入PID。
- 丢识别后的前`800 ms`最多保持最后有效方向的`2.5°`恢复倾角，帮助边缘钢球重新进入视野；持续超时后再让杆角以`15°/s`缓慢回到`0°`，避免长时间盲控。
- 最终机械单向限位为`-12°～+7°`。
- `roll <= -12°`时禁止丝杆继续上升，但允许下行退出。
- `roll >= +7°`时禁止丝杆继续下沉，但允许上行退出。
- 上位机超时、CRC持续失败、偏移量为NaN/Inf、DM-IMU失效、3508反馈超时均停止。
- 触发限位时清除偏移外环积分，防止离开限位时突然反冲。

## 第一轮调参顺序

1. 先验证`var1082`偏移量方向和`var1089`杆角方向。
2. 方向错误时只改`knexus_offset_input_sign`。
3. 从小到大调整`knexus_offset_kp`，让钢球明显回中。
4. 抖动时增加D或降低Kp；响应过慢时增加Kp。
5. 只有存在稳定静差时才少量增加Ki。

默认参数集中在`knexus_config.h`的“9.5 上位机偏移量丝杆归中”。运行时普通
变量可通过OctoLink/GDB修改，确认后再写回宏定义。
