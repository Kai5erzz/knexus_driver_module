# 全板硬件验收模式

当前 `knexus_config.h` 已选择 `KNEXUS_MODE_BOARD_TEST`。这个模式通过统一板级抽象
运行，同一份程序逻辑支持STM32和MSPM0。

## 安全操作

1. 首次运行必须架空车轮。
2. 上电后电机保持关闭。
3. 长按KEY0一秒，启用或关闭电机循环测试。
4. KEY1在任何时刻立即停车并解除使能。
5. 电机占空比硬上限为30%。

验收时允许翻转底板测量，因此仅在这个模式中绕过姿态安全停车。其它工作模式仍执行
完整安全检查。

## 自动测试内容

- LED0：由主任务每500 ms翻转，证明调度器仍在运行。
- LED1：电机已解锁时点亮。
- LED2：每250 ms翻转。
- 蜂鸣器：启动、解锁、停机和错误分别给出不同长度提示音。
- BMI088：持续更新加速度、陀螺仪、姿态和温度。
- 恒温加热：目标40℃，输出当前温度、目标温度和PWM占空比。
- CAN1/CAN2：每100 ms发送标准帧 `0x701`/`0x702`。
- DJI M3508：C620拨码ID=1，长按KEY0解锁后以约±3000 RPM正反交替。
- 循迹：输出8路ADC原始值、归一化值、线误差和扫描状态。
- 电机：依次测试左轮低/中/高、右轮低/中/高、双轮中/高，每档2秒。
- 编码器与电流：输出左右轮速度、占空比、电流和累计位置。

CAN载荷为：

```text
4B 4E 58 42 seq_lo seq_hi armed bus
```

前四字节是ASCII `KNXB`，最后一字节在CAN1为1、CAN2为2。

## OctoLink变量

BMI088保留驱动层ID `20..25`。全板验收数据使用：

| ID | 内容 |
|---:|---|
| 600 | 系统时间ms |
| 601..604 | 电机解锁、测试阶段、左右目标占空比 |
| 605..608 | KEY0、KEY1、LED1、LED2 |
| 609..614 | 两路CAN最近状态、成功数、失败数 |
| 615..621 | BMI088状态、帧数、温度、加热占空比与目标温度 |
| 622..629 | 左右实际速度、占空比、电流与编码器位置 |
| 630..637 | 8路循迹ADC原始值 |
| 638..645 | 8路循迹归一化值 |
| 646..649 | 线误差、扫描状态、更新计数、安全等级 |
| 650..652 | 车间消息数、路口次数、最近路口类型 |
| 653..655 | 3508初始化状态、目标RPM、斜坡后的目标RPM |
| 656..659 | 3508实际RPM、电流原始量、温度、PID输出 |
| 660..664 | 3508发送成功/失败、反馈数、发送状态、反馈年龄 |
| 665 | STM32上次复位原因寄存器RSR原始值 |
| 666 | 3508非阻塞CAN发送忙/超时累计次数 |
| 667 | STM32 1 ms快速任务超期累计次数（MSPM0为0） |
| 668 | STM32快速任务单次最大耗时ms（MSPM0为0） |

该模式的验收输出由 `KNEXUS_BOARD_TEST_OCTO_ENABLE` 单独控制，即使普通周期调试总开关
关闭，也会正常输出全板测试数据。

3508在STM32上使用FDCAN2，在MSPM0上使用其唯一的MCAN。控制帧ID为`0x200`，
反馈帧ID为`0x201`，CAN速率沿用底板的1 Mbps配置。目标速度每3秒换向，并通过
12000 RPM/s的斜坡跨过零速，避免从+3000 RPM瞬间跳到-3000 RPM。

3508未连接或反馈超时时属于正常降级状态：控制器只低频发送探测帧，CAN发送全程
非阻塞，不能影响LED、蜂鸣器、OctoLink、IMU或底盘任务。收到新鲜`0x201`反馈后
自动恢复1 kHz速度闭环。

## 参数位置

所有参数都位于 `common/User/config/knexus_config.h` 的“全板硬件验收模式”区域：

```c
#define KNEXUS_BOARD_TEST_MOTOR_MAX_DUTY       0.30f
#define KNEXUS_BOARD_TEST_MOTOR_MAX_SPEED_MPS  0.30f
#define KNEXUS_BOARD_TEST_MOTOR_SEGMENT_MS     2000U
#define KNEXUS_BOARD_TEST_CAN_PERIOD_MS         100U
#define KNEXUS_BOARD_TEST_OCTO_ENABLE             1U
```

底盘电机验收使用开环10%/20%/30%占空比，不使用编码器速度闭环；3508速度、
换向时间和PID参数紧随其后，使用 `KNEXUS_DJI_*` 前缀。
