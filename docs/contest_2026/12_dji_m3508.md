# DJI M3508/C620驱动

该模块由队友移植版本整理而来，保留DJI协议、反馈解析和速度PID，并适配当前工程的
`knx_can_bus`统一总线。驱动层不再直接依赖STM32的FDCAN句柄，因此STM32和MSPM0
可以使用相同API。

## 硬件与CAN

- 电机：DJI M3508
- 电调：C620
- 电调拨码：ID=1
- 控制帧：标准ID `0x200`
- 反馈帧：标准ID `0x201`
- 数据长度：8字节
- 波特率：1 Mbps
- STM32总线：FDCAN2
- MSPM0总线：唯一的MCAN

一个`0x200`帧最多包含ID 1..4四台电机的电流指令。当前测试注册ID 1，使用载荷
第0、1字节，其余槽位保持为零。

## 软件分层

- `common/User/drv/dji_motor`：协议、对象注册、反馈解析、控制帧组包。
- `common/User/modules/dji_motor_ctrl`：M3508速度PID、目标斜坡、CAN订阅和诊断。
- `knexus_mode_board_test.c`：按键安全逻辑和正反交替测试。

控制器在1 ms快速任务运行。未按KEY0解锁时不会持续占用CAN，只在停机瞬间发送一次
零电流帧。KEY1会清除目标、PID积分并发送零电流指令。

## 测试流程

1. 架空M3508输出轴，确认C620拨码为1。
2. 接入对应CAN接口和电机电源。
3. 上电后确认OctoLink变量653为0，表示初始化成功。
4. 长按KEY0一秒解锁。
5. 目标从0斜坡到+3000 RPM，之后每3秒改变方向。
6. KEY1应立即将目标、斜坡目标和PID输出清零。

## 参数

参数位于`knexus_config.h`：

```c
#define KNEXUS_DJI_TEST_SPEED_RPM             3000.0f
#define KNEXUS_DJI_TEST_REVERSE_PERIOD_MS     3000U
#define KNEXUS_DJI_TARGET_SLEW_RPM_PER_S     12000.0f
#define KNEXUS_DJI_MAX_TARGET_RPM             6000.0f
#define KNEXUS_DJI_SPEED_KP                      15.0f
#define KNEXUS_DJI_SPEED_KI                       0.001f
#define KNEXUS_DJI_SPEED_KD                       0.0f
#define KNEXUS_DJI_PID_MAX_CURRENT_CMD         12000.0f
```

先确认反馈RPM方向和目标一致，再调整PID。若反馈数始终为0，不要继续增大PID，应检查
电调ID、CAN接线、终端电阻、波特率和所选总线。

## OctoLink

| ID | 内容 |
|---:|---|
| 653 | 初始化状态，0为成功 |
| 654 | 请求目标RPM |
| 655 | 斜坡后的目标RPM |
| 656 | 实际RPM |
| 657 | C620反馈的转矩电流原始量 |
| 658 | 电机温度℃ |
| 659 | PID电流指令 |
| 660 | 控制帧发送成功数 |
| 661 | 控制帧发送失败数 |
| 662 | 反馈帧接收数 |
| 663 | 最近发送状态 |
| 664 | 最近反馈年龄ms；无反馈时为`0xFFFFFFFF` |
