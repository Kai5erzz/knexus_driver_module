# JC4310 连杆运动补偿模式

该模式用于在底盘不发车、人工前后推动小车时，验证无刷连杆对底盘纵向加速度的补偿效果。控制链为：

`底盘 BMI088 加速度 -> 运动补偿目标杆角 -> DM-IMU-L1 杆角反馈 -> JC4310 力矩控制`

底盘电机、C620/3508 与视觉闭环均不参与本模式。

## 硬件与已标定极性

- JC4310：FDCAN2，电机 ID `3`，发送 ID `0x603`，反馈 ID `0x583`。
- DM-IMU-L1：FDCAN1，安装方向保持不变，输出处理后的杆角 roll。
- 杆角机械零位：2026-07-31T10:55:16主动扶正稳定段中位数为`-0.824853°`、标准差约`0.014°`；驱动统一输出`roll_corrected = roll_raw + 0.824853°`。
- 底盘 BMI088：提供经过姿态补偿和静态偏置校准的纵向加速度。
- 动态采样复核后的极性：`正力矩 -> 电机位置增加 -> roll 增大`。
- 反向关系：`负力矩 -> 电机位置减小 -> roll 减小`。

## 操作流程

1. 上电后不要移动小车。程序自动进入 JC4310 伺服/力矩模式，并持续发送 `0 N·m`。
2. 等待 LED2 点亮，并确认 `var1217=1`、`var1218=1`、`var1219=1`。
3. 按一下 KEY0 启动运动补偿；此时 `var1216=1`。
4. 人工先向前推动、再向后推动小车，观察目标杆角、实际杆角和力矩响应。
5. 按一下 KEY1 立即停止补偿并恢复持续发送 `0 N·m`。

如果偏置尚未学习完成、底盘 IMU 无效、杆角无效或 JC4310 未就绪，KEY0 不会启动，蜂鸣器会长鸣提示。

## 限位

- 主动编码器限位为`-46°～+39°`；这些值都是JC4310编码器角度，不是DM-IMU-L1的roll。
- 控制器按当前编码器速度预测`80 ms`后的位置；距离任一限位`8°`开始削弱外向力矩并加入速度阻尼。
- 越过软件限位后锁存恢复方向，不再使用大力矩脱困脉冲。恢复控制采用“位置误差→限速目标→速度环”：目标速度不超过 `30°/s`，正常回区驱动力不超过 `0.12 N·m`。
- 越过边界后位置PD主动拉回边界内`2°`，即目标`-44°/+37°`；反向退出始终允许。
- 最小脱困力矩只在其方向与回区目标速度一致时生效；如果已经冲得过快，速度环可以立刻换成反向制动，避免“最小回拉力矩”反而继续把机构推向另一端。
- 越出保护外边界时绝不允许继续向外施力，但始终允许向安全区退出。
- 所有限位阻尼和脱困力矩在最终发送前再次限制到 `±0.50 N·m`，禁止叠加突破电机峰值。
- 普通高速换向同样使用“短脉冲脱困 + 180 ms柔和回拉”，解决合力换号慢和反向持续大力矩导致的二次超调。
- DM-IMU 杆角目标单独限制在 `-10°` 到 `+5°`。杆角与电机编码器角度不是同一种角度，不能相互代替。
- 编码器位置超过 `150 ms` 未更新、DM-IMU-L1 数据失效、JC4310 通信失败或驱动器报错时，命令立即变为零力矩。

## 第一版参数

参数位于 `common/User/config/knexus_config.h`：

| 参数 | 初值 | 作用 |
|---|---:|---|
| `KNEXUS_JC4310_ANGLE_KP_DEFAULT` | `0.055` | 杆角误差到力矩的比例增益 |
| `KNEXUS_JC4310_ANGLE_KI_DEFAULT` | `0.004` | 克服重力和静摩擦造成的稳态偏差 |
| `KNEXUS_JC4310_ANGLE_KD_DEFAULT` | `0.0070` | 杆角速度阻尼，抑制动态过冲 |
| `KNEXUS_JC4310_ANGLE_I_LIMIT_NM_DEFAULT` | `0.080 N·m` | 积分力矩上限，用于建立静态保持力 |
| `KNEXUS_JC4310_DOWN_KP_GAIN` | `1.35` | 下沉（正roll误差）方向的比例刚度补偿 |
| `KNEXUS_JC4310_MAX_TORQUE_NM_DEFAULT` | `0.50 N·m` | 使用电机允许的峰值力矩 |
| `KNEXUS_JC4310_TORQUE_SLEW_NMPS_DEFAULT` | `45.00 N·m/s` | 普通力矩命令斜率；换向脉冲和柔和回拉分别使用独立斜率 |
| `KNEXUS_JC4310_D_GUARD_ERROR_DEG` | `1.0°` | 大误差区启用D项反向保护；近目标仍保留完整阻尼 |
| `KNEXUS_JC4310_D_OPPOSE_P_MAX_RATIO` | `0.75` | 大误差时D项最多抵消75%的P项，不允许提前反向驱动 |
| `KNEXUS_JC4310_ACCEL_LPF_HZ` | `5 Hz` | 底盘加速度前馈滤波带宽 |
| `KNEXUS_JC4310_TARGET_ROLL_SLEW_DPS` | `140°/s` | 目标杆角变化率 |
| `KNEXUS_JC4310_STARTUP_BLEND_MS` | `700 ms` | 启动时先接住当前杆角，再平滑过渡到上层目标 |
| `KNEXUS_JC4310_STARTUP_MAX_TORQUE_NM` | `0.14 N·m` | 启动交接阶段的力矩上限 |
| `KNEXUS_JC4310_STATIC_TORQUE_NM` | `0.035 N·m` | 小误差、低速度时的连续静摩擦补偿峰值 |
| `KNEXUS_JC4310_LIMIT_LOOKAHEAD_S` | `0.080 s` | 编码器限位预测时间 |
| `KNEXUS_JC4310_LIMIT_RECOVERY_MAX_VEL_DPS` | `30°/s` | 越界回区速度上限，限制限位后的摆锤速度 |
| `KNEXUS_BALL_ACCEL_COMP_GAIN_DEFAULT` | `1.15` | 底盘加速度前馈强度 |
| `KNEXUS_BALL_DRAG_S_INV_DEFAULT` | `0` | 小球等效阻力，视觉未接入前保持为零 |

运行时也可通过符号 `knexus_jc4310_angle_kp`、`knexus_jc4310_angle_kd`、`knexus_jc4310_max_torque_nm` 和 `knexus_jc4310_torque_slew_nmps`观察当前值。

采样时至少保留 `1205、1206、1207、1209、1210、1211、1214、1215、1216、1220～1222`，这样可以区分“加速度补偿目标不足”“杆角内环跟不上”和“限位截断”三类问题。

模式4采样曾出现 DM-IMU 时间戳比应用层 `context->now_ms` 新1～2ms 的正常并发
现象。旧代码使用无符号减法，年龄会下溢成约 `4294967294 ms`，继而周期性把
杆角反馈判失效并清零力矩。现在改用函数内当前时钟和有符号差值，轻微未来时间
按0ms处理，防止视觉归中与运动补偿在行驶中反复掉线。
